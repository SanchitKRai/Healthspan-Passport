## 3. Safety, Human-in-the-Loop & Failure Mode Analysis

1. **Unflagged Error Protection:**
   Values parsed below 80% confidence, via multi-line OCR association, or outside `PHYSIOLOGICAL_LIMITS` are marked `needs_review: true`, requiring explicit confirmation before PhenoAge is computed. Ambiguous ties emit `value: null` rather than guessing.
2. **Failure UX & Manual Entry Fallback:**
   When fewer than 3 biomarkers are extracted or low-confidence items are flagged, the UI warns *"We couldn't read this reliably"* and exposes manual entry for all 9 PhenoAge markers plus the routine panel.
3. **Missing Biomarker Integrity:**
   When essential tests (such as hs-CRP) are absent, the PhenoAge engine returns `phenoage: null` and lists the missing markers rather than imputing them.
